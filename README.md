# QuimiTrack — Tech Challenge Fase 1

## Sobre
Proposta de sistema para gestão de cargas químicas em contexto portuário, inspirada em operações logísticas do Porto de Santos.

## Objetivo
Organizar produtos, cargas, classificação de risco, documentação, responsável técnico, inspeção, status e histórico, estabelecendo a base para evolução full stack nas próximas fases.
